FramePilot — стартовый проект мода Fabric для Minecraft Java 1.21.11

Важно:
- Нужен JDK 21.
- Это первая диагностическая версия: показывает FPS и среднее время кадра.
- Код не был скомпилирован в среде создания архива. Сначала запусти сборку и проверь результат.
- Для сборки нужен Gradle: в PowerShell из папки проекта выполни `gradle build`.
- Если появится ошибка API/версии, пришли полный текст ошибки — можно исправить проект.
- Нагрузка 60% GPU / 40% CPU не может быть гарантирована модом; зависит от сцены, настроек, драйвера и других модов.
